## Fresh library import proof

Command:

```bash
mkdir /tmp/goncho-proof && cd /tmp/goncho-proof
go mod init goncho-proof
GONOSUMDB= GOPRIVATE= GOPROXY=https://proxy.golang.org,direct \
  go get github.com/TrebuchetDynamics/goncho/service@v0.3.1
cat > main.go <<'GO'
package main

import (
    "fmt"

    goncho "github.com/TrebuchetDynamics/goncho/service"
)

func main() {
    cfg := goncho.Config{}.Effective()
    fmt.Printf("import-ok workspace=%s tools-ready\n", cfg.WorkspaceID)
}
GO
go run .
go list -m github.com/TrebuchetDynamics/goncho
```

Observed result:

```text
import-ok workspace=gormes tools-ready
github.com/TrebuchetDynamics/goncho v0.3.1
```
